# 青岛住房公积金官方资料与 Hermes Skill

本仓库用于系统整理**国家层面及青岛市住房公积金相关的公开官方文件**，并提供一个可供 Hermes Agent 使用的青岛住房公积金查询与办事辅助 Skill。

> 当前正在进行官方资料普查与效力核验，计划于 2026-08-03 08:30（北京时间）形成首版审校结果。截至 2026-08-02，目录已录入 4 条国家级记录：3 个财政部/国务院完整正文页面，以及《住房公积金呆账核销管理暂行办法》的 1 条财政部官方引用链；青岛文件尚未完成录入。

## 重点文件

首版必须收录并核验：

- 《住房公积金呆账核销管理暂行办法》

本轮已由财政部财综〔2007〕22号官方正文确认该办法的标题、发布机关和文号（财综〔2006〕10号），但尚未取得官方全文，发布日期、效力状态及条款内容仍待核验。仓库将继续单独记录官方全文或扫描件、附件哈希以及与青岛实际工作的适用关系；不会用第三方转载补齐缺失条款。

## 收录范围

### 国家层面

- 行政法规和国务院政策；
- 住房城乡建设部、财政部、人民银行、税务总局等部门发布的规章、规范性文件和政策解释；
- 缴存、提取、贷款、转移接续、财务会计、行政执法、信用管理、风险处置和呆账核销文件；
- 全国住房公积金服务事项、数据标准和公开办事指引。

### 青岛层面

- 青岛市地方性法规、政府规章和市政府规范性文件；
- 青岛市住房公积金管理委员会及青岛市住房公积金管理中心公开政策；
- 缴存、提取、贷款、商转公、异地转移、灵活就业、行政执法、信用评价和服务指南；
- 重要历史文件及其废止、替代、修订关系。

## 官方来源原则

主证据仅接受：

- 中国政府网及国务院公报；
- 住房城乡建设部、财政部、人民银行、税务总局等中央部门官网；
- 山东省、青岛市人民政府及政府公报；
- 青岛市住房公积金管理中心及官方政府信息公开附件；
- 其他依法公开的官方法规规章数据库。

商业网站、论坛、公众号和文库只能作为发现线索，不能作为最终依据。

sources/catalog.csv             机器可读来源目录

sources/qingdao/                青岛官方文件或官方附件

## 使用方式

将仓库作为 Skill 目录加载，或把 `SKILL.md` 及其 `references/`、`sources/`、`scripts/` 保持在同一目录下。回答具体问题时，应先确定事项类型和发生日期，再按“上位法 → 青岛现行政策 → 官方办事指南”的顺序查证。

## 重要声明

- 本仓库是官方公开资料索引和辅助检索工具，不构成法律意见，也不替代青岛市住房公积金管理中心的正式答复。
- 政策可能更新；涉及资格、额度、利率、期限、材料和办理结果时，必须复核最新官方页面。
- 官方文件原文及附件的权利和解释权归发布机关；仓库中的脚本与 Skill 文本另行按仓库许可证约定。
- 对无法确认效力状态或无法取得官方全文的文件，会明确标为“待核验”，不会推断为现行有效。
