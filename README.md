# 青岛住房公积金官方资料与 Hermes Skill

本仓库系统整理**国家层面及青岛市住房公积金公开官方文件**，并提供可供 Hermes Agent 使用的青岛住房公积金查询与办事辅助 Skill。

> 官方资料普查与效力核验仍在进行，计划于 2026-08-03 08:30（北京时间）形成首版审校结果。截至 2026-08-03，目录有160条记录：国家级28条、青岛132条。该数量只代表当前已核验范围，不表示资料已经找齐；同一政策的 HTML、中央机关发布通知与主管机关官方转载或附件分别建档时也不应重复计作多项政策。

## 重点文件：住房公积金呆账核销管理暂行办法

仓库已取得六安市住房公积金管理中心官网发布的财综〔2006〕10号完整 HTML 正文，通过财政部财综〔2007〕22号交叉确认标题、发布机关、文号及风险准备金用途，并在国务院公报所载2011年住建部清理目录中确认：建金管函〔2006〕26号转发通知当时列为继续有效。

当前可确认：

- 发布机关：财政部；文号：财综〔2006〕10号；
- 发布及施行日期：2006-01-27；
- 正文含通知和办法第一至第六章，共28条；
- 住建部转发通知在2011年清理时列为继续有效，但这只是历史效力快照；
- 本地归档及 SHA256 已写入目录。
- 财务办法第二十五条提供省级财政批准核销链，会计办法提供经批准核销及后续收回的会计处理，补充规定又明确抵押物处置不足额应列“其他应收款”并按债务人设明细账；青岛2016年年度报告进一步披露以前年度核销贷款收回1.85万元。这些证据支持严格区分核销审批、账务处理、后续收回与债权状态。

尚不能无条件断言该办法永久现行有效：目前仅能表述为“未发现废止依据，2011年住建部清理目录确认其转发通知当时继续有效，仍待财政部当前规范性文件清理目录终核”。财政部原站全文或扫描件、住建部转发通知全文、山东省实施文件、青岛本地风险准备金与核销制度及2016年前原始核销审批档案仍是优先缺口。任何回答都不得把账务核销解释为债权或债务当然消灭，也不得把报告中的负数核销误作当年新增核销。

## 官方来源原则

主证据只接受：

- 中国政府网、国务院公报和国家法规数据库；
- 住房城乡建设部、财政部、人民银行、税务总局等中央部门官网；
- 山东省、青岛市人民政府及政府公报；
- 青岛市住房公积金管理中心官方网站及政府信息公开附件；
- 其他依法公开的官方法规规章数据库。

商业网站、论坛、公众号和文库只能作为检索线索，不能作为最终依据。

## 使用方式

将仓库作为 Skill 目录加载，或保持 `SKILL.md`、`references/`、`sources/` 和 `scripts/` 的相对位置。回答具体问题时：

1. 先确定事项类型和发生日期；
2. 按“上位法 → 青岛现行政策 → 官方办事指南”检索；
3. 区分正文落款日、网页发布时间、施行日和到期日；
4. 对年度参数及清理目录发布后的变化再次访问官方页面；
5. 对关键结论给出文件名、文号、适用日期和官方 URL。
