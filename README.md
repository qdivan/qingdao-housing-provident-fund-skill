# 青岛住房公积金官方资料与 Hermes Skill

本仓库系统整理**国家层面及青岛市住房公积金公开官方文件**，并提供可供 Hermes Agent 使用的青岛住房公积金查询与办事辅助 Skill。

> 官方资料普查与效力核验仍在进行，计划于 2026-08-03 08:30（北京时间）形成首版审校结果。截至 2026-08-02，目录有19条记录：国家级4条、青岛15条。该数量只代表当前已核验范围，不表示资料已经找齐。

青岛15个官方 HTML 页面已归档到 `sources/qingdao/`，并记录 SHA256、访问日期和 OCR 状态。

尚不能无条件断言该办法永久现行有效：目前仅能表述为“未发现废止依据，待财政部规范性文件清理目录终核”。财政部原站全文或扫描件、山东省实施文件、青岛本地风险准备金与核销制度仍是优先缺口。任何回答都不得把账务核销解释为债权或债务当然消灭。

## 官方来源原则

主证据只接受：

- 中国政府网、国务院公报和国家法规数据库；
- 住房城乡建设部、财政部、人民银行、税务总局等中央部门官网；
- 山东省、青岛市人民政府及政府公报；
- 青岛市住房公积金管理中心官方网站及政府信息公开附件；
- 其他依法公开的官方法规规章数据库。

商业网站、论坛、公众号和文库只能作为检索线索，不能作为最终依据。

## 使用方式

将仓库作为 Skill 目录加载，或保持 `SKILL.md`、`references/`、`sources/` 和 `scripts/` 的相对位置。回答具体问题时：

1. 先确定事项类型和发生日期；
2. 按“上位法 → 青岛现行政策 → 官方办事指南”检索；
3. 区分正文落款日、网页发布时间、施行日和到期日；
4. 对年度参数及清理目录发布后的变化再次访问官方页面；
5. 对关键结论给出文件名、文号、适用日期和官方 URL。
